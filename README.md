# PETLIO Pet Care

PETLIO is a pet care website built with Next.js, React, TypeScript, and Tailwind CSS. Site content and brand settings are stored in `data/templates.json`, with shared data types in `types/templates.types.ts`.

## Development

```bash
npm run dev
```

Open http://localhost:3000 to view the site.

## Available commands

- `npm run build` creates a production build.
- `npm run lint` runs ESLint.
- `npm start` starts the production server.
